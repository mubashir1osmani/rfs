# Nori iOS demo

## Start

1. Open `Nori.xcodeproj` in Xcode.
2. Select an iPhone simulator.
3. Run the **Nori** scheme.

No API credentials are required for the guided demo.

## 90-second walkthrough

1. On **Home**, show today's priorities, protected time, and next calendar block.
2. Tap **Watch a 20-second action demo**.
3. Nori creates a task, focus block, meeting invite, and email draft in one conversation.
4. Point out that the safe task is added automatically while external actions wait for approval.
5. Approve the focus block and grant Calendar access when iOS asks.
6. Open **My day** to show the new native calendar block and progress.
7. Return to **Nori**, tap the microphone, and say: “Block 90 minutes for focused study tomorrow at 9:30 AM.”
8. Open **Settings** to explain autonomy, connections, and the approval boundary.

## Additional prompts
