# Nori demo walkthrough

## Start

```bash
npm install
npm run demo
```

Open the app in Expo Go or an iOS simulator. The demo works without API credentials through Nori's local planner.

## 90-second product story

1. On **Home**, point out today's priorities, protected time, and the next calendar block.
2. Tap **Watch a 20-second action demo**.
3. Nori produces a task, focus block, meeting invite, and email draft in one conversation.
4. Show that the safe task is added automatically when autonomy is enabled.
5. Review the calendar and communication cards before approving them.
6. Open **My day** to show the newly planned schedule and task progress.
7. Open **Settings** to explain local mode, connected AI, Google integrations, and approval boundaries.

## Live prompts

- `Plan and time block my day around my open priorities.`
- `Book a 30 minute meeting with alex@example.com tomorrow at 3 PM.`
- `Email my professor that I need an extra day on the assignment.`
- `Block 90 minutes for focused study tomorrow at 9:30 AM.`
